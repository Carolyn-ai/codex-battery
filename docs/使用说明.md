# Codex 电量管家使用说明

## 首次使用

确认你已安装并登录自己的 Codex。启动电量管家后，在 Mac 顶部菜单栏找到电池图标；它是菜单栏应用，不一定出现在 Dock。再次打开应用会显示首次使用与状态窗口。

电池是 Codex 剩余用量的示意，不是电脑电池。工具默认每分钟刷新额度、每五分钟检查公开消息。数据超时、登录失效或来源不可用时会说明，不能据此认定用量归零或已重置。

## 菜单选项

可切换 Codex 返回的用量周期，或自动显示限制较紧的周期。周期名称使用返回的实际时长，不强制把短周期叫作五小时。倒计时采用本人账号的重置时间；可关闭显示。

公开预告、时间补充、改期和完成确认按版本分别提醒。打开菜单展示消息摘要后，当前版本记为已读；之后有有效变化会再次提醒。普通评论、仅有猜测的内容和未经作者核对的时间不会当作确定公告。也可手动粘贴 Tibo 公开原帖链接补查。

个人保留线是自己的计划，不是账号限制。便签只存于本机。登录时启动默认由用户选择；关闭该选项会移除本工具的启动项。

## 隔离演示

从菜单进入隔离演示，按按钮体验新预告、查看已读、补充时间、改期、撤回和完成确认。界面会明确标注“虚构示例”。退出演示后恢复真实状态。演示成功不等于真实消息已到，也不验证本人账号余额。

## 常见问题

**未找到 Codex／需要登录**：打开 Codex，完成自己的正常登录，再点重新检查。工具会查找标准的 Codex / ChatGPT 安装位置及常见 Codex CLI 路径。自定义安装位置可能需要调整 `Source/UsageClient.swift` 的候选路径。

**只看到部分周期**：以 Codex 实际返回为准；没有返回的周期不会伪造。

**公开消息暂不可用**：不影响额度查询。社区发现源和 X 公开端点可能限流、变更或遗漏消息；可以稍后重试或打开原帖核对。

**macOS 拦截打开**：发布包采用临时签名，未做 Apple 公证。确认来源后按系统提示在“系统设置 → 隐私与安全性”允许打开。不要关闭 Gatekeeper 或安装来历不明的描述文件。也可自行从源码构建。

**安装遇到不同主版本**：安装器会停止以保留现有版本。请使用另一 macOS 用户体验独立版，或自行核对后管理版本；不要直接覆盖。

## 卸载与恢复

1. 在菜单中关闭“登录时自动启动”，再退出电量管家。
2. 在访达的“前往文件夹”中打开 `~/Applications`，把“Codex 电量管家.app”移到废纸篓。若你原来装在系统应用目录，则使用原位置。
3. 若想一并移除设置，可把以下电量管家专属项目移到废纸篓：`~/Library/Preferences/local.codex-battery.plist`、`~/Library/Application Support/Codex Battery`、`~/Library/LaunchAgents/local.codex-battery.plist`。
4. 同主版本升级备份位于 `~/Library/Application Support/Codex Battery Backups`，确认不需要恢复前保留。备份包含个人设置，请勿公开上传。

需要恢复时，将旧应用放回原位置，退出应用后再还原备份的对应设置。不要移动或删除 Codex 自己的认证、聊天或工作目录。
