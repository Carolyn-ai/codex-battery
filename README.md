# Codex 电量管家

一个住在 macOS 菜单栏里的 Codex 用量电池。看剩余用量、看账号周期倒计时，也能查看公开的 Codex 重置消息。

**灵姐说 AI · Ling Talk AI** ｜ macOS 14+ ｜ Swift / AppKit ｜ MIT

## 下载安装

1. 打开 **[最新版下载](https://github.com/Carolyn-ai/codex-battery/releases/latest)**，下载 `CodexBattery-1.5.2-macOS.zip`。
2. 解压，双击 **`一键安装.command`**。应用安装到你的“应用程序”目录，并在菜单栏显示电池。
3. 首次使用前，安装并登录你自己的 Codex。工具会通过本机 Codex 查询你自己的用量。

安装包同时包含 Apple Silicon 和 Intel 架构。无需填写 API Key，也无需提供账号密码。应用采用本地临时签名，尚未经过 Apple 公证；如 macOS 阻止打开，请在确认来源后按系统提示到“系统设置 → 隐私与安全性”中允许该应用。不会自动关闭系统安全保护。

## 从源码安装

需要 macOS 14+、Apple Command Line Tools（`xcode-select --install`）以及已登录的 Codex。

```sh
git clone https://github.com/Carolyn-ai/codex-battery.git
cd codex-battery
./install.sh
```

也可以下载 GitHub 的源码 ZIP，解压后双击 `一键安装.command`。源码安装会在本机构建，不下载第三方脚本依赖。

## 能做什么

- **用量电池**：显示 Codex 返回的实际剩余比例，支持选择周期或自动显示限制较紧的周期。
- **重置倒计时**：区分本人账号的周期重置时间与公开活动消息；不猜测额度。
- **公开消息提醒**：新预告、明确时间补充、改期、撤回、完成确认，按有效新版本提醒；查看摘要后记为已读。
- **个人保留线与便签**：保存在本机，方便安排自己的使用节奏。
- **登录时启动与时区显示**：可在菜单中设置，默认北京时间。
- **隔离演示**：无需等待真实公告，即可体验“预告 → 查看已读 → 补时间 → 改期 → 撤回 → 完成”；退出后恢复真实状态。

公共消息来自社区发现源，并向 X 的公开内容端点核对作者与正文。采集可能延迟、遗漏或暂不可用，不代表 OpenAI 官方推送。**消息发布不等于你的账号已增加余额**，账号读数始终由本机 Codex 提供。查询失败时显示暂不可用，不把未知显示为满电。

## 隐私与本地数据

项目不包含作者的账号、真实用量、私有聊天、登录凭证或本机设置。使用时不需要把这些信息发给作者。登录由用户自己的 Codex 管理；本项目不打开登录文件。

工具不会读取聊天或文件内容、发送邮件、执行模型任务或上传用量。额度查询只执行本机 `app-server` 的初始化和 `account/rateLimits/read`。公开消息请求与账号读数分开，不携带账号读数或凭证。详情见 **[PRIVACY.md](PRIVACY.md)**。

## 使用、检查与卸载

- [使用说明](docs/使用说明.md)：首次启动、菜单选项、演示、常见问题和手动卸载。
- `./install.sh --dry-run`：只看安装目标，不改动本机。
- `./test.sh`：运行解析、异常处理、消息规则、已读与演示隔离检查；不会查询真实账号。
- `./build.sh --universal`：构建两个 Mac 架构。
- `./scripts/package.sh`：制作通用安装包及 SHA-256 校验文件。
- `python3 scripts/privacy_check.py`：检查公开文件边界与常见敏感信息模式。

安装遇到同名无关应用、多个安装副本或不同主版本时会停止，避免意外覆盖。升级同一主版本前，会在本机备份原应用与设置。备份及运行数据不进入仓库。

本项目为独立社区工具，与 OpenAI 无隶属关系。协议或公开来源改变时可能需要更新。
